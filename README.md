# Crystal Beauty Salon

A modern, responsive website for **Crystal Beauty Salon**.

## ✨ Features

- Clean and elegant design
- Fully responsive (works on mobile, tablet & desktop)
- Image gallery
- Staff section
- SEO-ready (includes `robots.txt` and `sitemap.xml`)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
